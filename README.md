# Keyring

Keyring is a simple password vault that I built to practice working with authentication, password security, and frontend development.

The idea is to have one place where I can manage passwords, generate stronger ones, and check how strong a password is.

## Features

* Store and manage passwords
* Search saved accounts
* Generate strong passwords
* Check password strength
* Add categories and notes to accounts
* Light / dark mode
* Copy generated passwords
* Runs directly in the browser

## Tech Used

* HTML
* CSS
* JavaScript

## Running it

Since this is a frontend project, there isn't much setup needed.

Just clone the repository and open `index.html` in your browser.

```bash
git clone <your-repository-url>
cd keyring
```

Then open `index.html`.

## Why I made this

I wanted to build something small but actually related to cybersecurity instead of just making another basic frontend project.

It helped me understand some of the practical parts of password management and security while also giving me something I could improve over time.

## Disclaimer

This is a learning project and shouldn't be used to store real or sensitive passwords.
